# Security policy

Version 0.1 is in initial development; no production release is currently supported.

Please report vulnerabilities privately using GitHub’s **Report a vulnerability** feature at https://github.com/BlackWare-AI/InsFollow/security/advisories/new when enabled. Do not publish sensitive vulnerabilities, credentials, authentication material or real account lists in public Issues.

If private reporting is unavailable, open a non-sensitive issue asking the maintainer to enable a private reporting channel, without revealing the vulnerability. Wait for a private channel before sending details. No private email address or response deadline is promised.

Include the affected revision, Android/WebView versions, impact and a minimal reproduction with fictional data. Do not send cookies, passwords, tokens or someone else’s data. Coordinate disclosure with maintainers and allow time to investigate and prepare a fix.
